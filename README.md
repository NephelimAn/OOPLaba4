# Лабораторная работа: алгоритм муравьёв

Приложение на Java с визуализацией Swing, без внешних библиотек. Задача: найти кратчайший замкнутый маршрут по всем городам полного неориентированного графа.

## Запуск

В IntelliJ IDEA выберите JDK 21 и запустите `src/Main.java` зелёной кнопкой у `main`.

Либо в PowerShell из папки проекта:

```powershell
./run.ps1
```

Скрипт использует `JAVA_HOME` или установленный IntelliJ JDK из `%USERPROFILE%/.jdks`. Java 8 из системного PATH не нужна.

Проверки алгоритма без открытия окна:

```powershell
./run.ps1 -Test
```

## Работа с программой

1. Выберите число городов, муравьёв, циклов и параметры α, β, ρ, Q.
2. Нажмите **Сброс / применить**. При одинаковом seed граф и случайные решения воспроизводятся.
3. **Старт** запускает анимацию, **Пауза** приостанавливает её. Скорость можно менять на ходу.
4. **Один переход** перемещает всех муравьёв на одну вершину. **Один цикл** завершает текущий тур всех муравьёв и обновляет феромон.
5. Синие рёбра показывают феромон, зелёные выделяют лучший найденный маршрут. Флажок отключает зелёное выделение для наблюдения самого феромона.
6. **Новый граф** увеличивает seed и начинает новый эксперимент. **Сброс / применить** с прежним seed повторяет эксперимент.

В таблице слева показаны длины, доля муравьёв с длиной рекордного маршрута и отклонение от точного оптимума. Точный алгоритм Held–Karp работает только при n ≤ 12 и служит для сравнения: он не подсказывает маршрут муравьям. При n > 12 программа использует только муравьиный алгоритм.

## Эксперименты для защиты

- **Равномерный случайный поиск:** α = 0, β = 0. Все непосещённые города равновероятны, феромон не влияет на выбор.
- **Обучение по феромону:** α = 1.5, β = 0, ρ = 0.35, 32 муравья, 200 циклов. При первом цикле все рёбра имеют одинаковый феромон, поэтому выбор равномерный. Далее вероятности меняются.
- **Учёт расстояния:** α = 1.5, β = 2, остальные параметры по умолчанию. Уже на первом цикле короткие рёбра вероятнее длинных, но выбор остаётся случайным.
- **Воспроизводимый пример из проверок:** 8 городов, seed = 42, 16 муравьёв, 100 циклов, α = 1.5, β = 2, ρ = 0.35, Q = 1. Получены длина 1.97319908 и совпадение с точным оптимумом.

Ant System относится к роевым метаэвристикам. Конечное число циклов не гарантирует глобального оптимума и полного совпадения маршрутов всех муравьёв. Программа показывает реальные результаты вероятностного поиска. Доля совпадений сравнивает длины с допуском 1e-9, а не порядок городов: циклические сдвиги и обратные маршруты эквивалентны.

## Структура

| Класс | Ответственность |
|---|---|
| `Node` | Номер и координаты города |
| `Edge` | Расстояние и феромон общего двунаправленного ребра |
| `Graph` | Города, рёбра и генерация графа |
| `Ant` | Память посещений, вероятностный выбор и перемещение |
| `Tour` | Неизменяемый проверенный замкнутый маршрут |
| `Parameters` | Проверенные параметры эксперимента |
| `AntColony` | Циклы, испарение, отложение феромона, статистика |
| `ExactSolver` | Независимая точная проверка |
| `GraphPanel` | Рисование графа, муравьёв и истории |
| `ColonyFrame` | Окно и обработка команд пользователя |
| `Main` | Точка входа |

Формулы:

```text
η(i,j) = 1 / d(i,j)
p(i,j) = τ(i,j)^α * η(i,j)^β / Σ[τ(i,k)^α * η(i,k)^β]
```

Сумма берётся только по непосещённым городам. Выбор выполняется рулеткой по этим вероятностям. После возвращения всех муравьёв в стартовые города:

```text
τ(i,j) = (1 - ρ) * τ(i,j) + Σ[Q / L(k)]
```

Вклад муравья k добавляется только на рёбрах его тура, включая последнее ребро возврата. В PDF обозначения обновления неоднозначны, поэтому здесь используется стандартная общая формула Ant System с ρ как долей испарения. Минимальное значение феромона 1e-12 защищает численные вычисления. Начальный феромон равен 1. Муравьи распределяются по городам максимально равномерно.
